# ✍️ The hand-written questions

One hundred questions about Magic: The Gathering cards, written by me before the graph's layout exists.

Most of TopDeck's questions are built from templates, and a template is shaped by the tables it will be answered from. These are the check on that: questions a player would ask, written before there were any tables to shape them. The Git history shows they came first.

## The rules I write them by

- One question to a line, numbered, ending in a question mark.
- Each is something I'd ask a friend who knows every card: about one card, about a kind of card, about artists, sets, colours, costs, or what cards do.
- I don't stop to wonder how it would be answered. Some will turn out to be impossible for every system, and that is a finding too.
- No two the same.
- Once all hundred are written, the page is frozen and never edited after a result is seen.

`uv run topdeck ground` counts them and checks each rule.
